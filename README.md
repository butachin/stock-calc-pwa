# かぶポケ (KabuPocket) - 株の計算＆NISAシミュレーター PWA

バックエンド不要・フロントエンド完結（`localStorage` 自動保存対応）のスマホ特化型株計算＆学習PWAアプリです。

## 主な機能（下部ナビゲーション4タブ構成）

1. **ナンピン・損益シミュレーター（`ナンピン`）**
   - 現在の保有株数・平均取得単価と、追加購入株数・株価から**新しい平均取得単価**と**損益分岐ラインの低下率**をリアルタイム計算
   - 「あと何%（何円）株価が戻ればプラス転換するか」をナンピン前後で比較表示
   - 予想・目標株価まで戻った場合の売却損益シミュレーター＆計算履歴の保存機能
2. **配当利回り・優待・新NISAシミュレーター（`配当・NISA`）**
   - **新NISA（非課税）** と **特定口座（約20.315%課税）** をワンタップで切り替え比較
   - 配当金だけでなく**株主優待の年間換算額**も含めた「総合利回り」と月平均のお小遣い換算額を表示
   - 「月〇万円の不労所得を得るにはいくら元本が必要？」を逆算する目標配当シミュレーター
3. **積立・複利シミュレーション（`積立・複利`）**
   - スライダー操作で「投資元本」と「運用収益」の積み上げ棒グラフ（Recharts）がリアルタイムに変化
   - 新NISAの生涯投資枠（1,800万円）到達年や、運用益が元本を上回るタイミングを自動判定
4. **マイ銘柄ノート＆割安度チェッカー（`株ノート`）**
   - 気になる銘柄・保有銘柄をメモ保存し、ワンタップで「ナンピン計算」「配当計算」へ数値を反映
   - **PER × PBR 割安度・推定ROEチェッカー**と、目安の数字がすぐわかる**株の勉強ミニ辞典**を搭載

## 開発サーバーの起動方法

```bash
cd stock-calc-pwa
npm run dev
```

同じWi-Fi内のスマホからすぐ実機確認したい場合：
```bash
npm run dev -- --host
```
表示された `Network: http://192.168.x.x:5173/` のURLをスマホで開くだけで確認できます。
また、Vercel や Cloudflare Pages に GitHub リポジトリを連携すれば、無料で HTTPS 公開＆スマホの「ホーム画面に追加（PWA）」が利用できます。
